- No paid services: static site on GitHub Pages (built by .github/workflows/deploy.yml). Books come from Project Gutenberg: the Gutendex catalog is called from the browser; book text goes through a tiny free Cloudflare Worker relay (cloudflare-worker/worker.js, address in src/config.ts) because Gutenberg sends no CORS headers. Translation from the free MyMemory API in the browser, audio from browser speech. Why: user requires zero hosting/API cost.
- All user data (progress, streak, saved words, uploaded books) is stored on-device (localStorage + IndexedDB); no accounts. Why: user chose device-only storage.
